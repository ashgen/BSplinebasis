## 2024-05-18 - Optimized Horner's scheme array evaluation in `evaluateInterval`
**Learning:** Found that reversing a loop in Horner's scheme array evaluation gives a nice speed up because we can avoid iterator overhead. `evaluateInterval` in `include/bspline/internal/misc.h` was changed from `for (auto it = coeffs.rbegin() + 1; it != coeffs.rend(); it++)` to `for (int i = static_cast<int>(size) - 2; i >= 0; --i)`. Also found that avoiding redundant operations, like getting indices relative to spline support inside an integration loop, offers noticeable speedups over many interval accesses. Changing `intervalIndexFromAbsolute(absIndex).value()` to `absIndex - aStartIndex` sped up evaluating `BilinearForm`, `LinearForm`, and numerical integration.
**Action:** When a method inside a hot loop returns an `std::optional` that requires `.value()`, and the bounds checking is redundant, bypass the method for a faster inline math calculation if possible.
