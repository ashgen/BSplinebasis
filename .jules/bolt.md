## 2024-05-18 - Avoid redundant `internal::make_array` with `std::vector`
**Learning:** Initializing a `std::vector` of `std::array` types (e.g., `std::vector<std::array<T, N>>(size)`) natively value-initializes the arrays, setting their elements to zero. Explicitly using `internal::make_array` with a prototype array to populate the vector elements introduces unnecessary overhead, slowing down vector initialization dramatically compared to built-in value initialization, especially when copying large numbers of elements.
**Action:** When initializing a vector of arrays to zero, rely on value initialization (`std::vector<std::array<T, N>>(size)`) rather than providing a prototype array via `make_array`. Additionally, avoid explicitly populating `std::array{}` elements if value initialization handles it safely natively.
