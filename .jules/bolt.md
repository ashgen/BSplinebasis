## 2024-05-13 - Value-Initialization Overhead in `make_array`
**Learning:** In C++, explicit loops copying the same value using custom struct/functions (like `make_array(0)`) are less efficient for initializing zeroed memory than the compiler's native value initialization (using `std::vector<std::array<T, N>>(size)` which zero-initializes). However, in specific cases like vector assignment overhead, `std::vector` initialization of multi-dimensional elements with value initialization reduces internal copying operations, often compiling to highly optimized block memory assignments (e.g., `memset`). Changing allocations from explicitly calling `make_array` to just using constructor sizing removes unnecessary copies.
**Action:** When initializing a vector of arrays to zero (e.g., in `bspline::Spline` linear combination or operators), use value-initialization by relying on `std::vector(size)` default value semantics. Remove `make_array<T, N>(0)`.
