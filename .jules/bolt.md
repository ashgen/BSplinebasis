## 2024-03-24 - Zero-initialization optimization
**Learning:** In this codebase, vectors of arrays are initialized heavily. Constructing `std::vector<std::array<T, N>>` with a size inherently value-initializes (zeroes) memory. Calling a custom `make_array` filled with zeros internally loops to perform assignments, completely undermining vector's optimized continuous-memory allocation and resulting in overhead (O(size * N)). Aggregrate initialization `std::array<T, N>{}` performs much better.
**Action:** Use vector size construction for default values where possible instead of explicitly looping assignments or passing explicit zero-initialized value copies. Opt for aggregate initialization `std::array<T, N>{}` over hand-rolled manual fill functions when `constexpr` or simply zero-initializing local arrays.
