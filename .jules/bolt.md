## 2024-10-26 - Optimize vector initialization by avoiding explicit zero-arrays
**Learning:** In C++, constructing a vector of arrays with an explicit zero-initialized array as the default value (e.g. `std::vector<std::array<T, N>> vec(size, make_array(0))`) results in constructing the prototype array and copying it to every element, which is significantly slower. Simply using `std::vector<std::array<T, N>> vec(size)` natively value-initializes (zeros) memory much faster, often compiling to an optimized `memset` operation.
**Action:** Replace `vector(size, make_array(0))` with `vector(size)` for scalar types when value initialization to zero is intended. Note that if only a portion of the array is overwritten (e.g. in `operator=`), explicitly ensuring all elements are zeroed is still required, but `vector(size)` handles this intrinsically anyway.
