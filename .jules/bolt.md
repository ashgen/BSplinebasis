## 2024-05-18 - Optimize position operator transform performance
**Learning:** Found that `std::array<T, size>` arrays being fully explicitly value-initialized zeroes out overhead, and more critically `Position::expandPower` in `Position.h` was recomputing combinations at runtime. Precomputing binomial coefficients via `constexpr` combined with `std::index_sequence` and removing the overhead of `fill(static_cast<T>(0))` by relying on aggregate initialization significantly speeds up transformations, cutting the transform time for large datasets by almost 3x.
**Action:** Use `std::index_sequence` to pass constexpr variables dynamically into compile time `std::array` initializers, and use `{}` aggregate initialization over `fill(0)` when all array entries will eventually be overridden or modified later anyway.
