## 2023-10-23 - Optimizing pure mathematical utility functions with constexpr
**Learning:** In C++17 and later, marking pure mathematical utility functions like `faculty`, `facultyRatio`, and `binomialCoefficient` as `constexpr` allows the compiler to perform constant folding at compile-time when parameters are known (e.g. from template arguments or fixed polynomial orders). In `bspline::operators::Position::transform`, the binomial coefficients are computed on every single function call based solely on the fixed template parameter `n`. Without `constexpr`, this requires O(n) loops inside the hot path on every call. With `constexpr`, the compiler folds these evaluations entirely, replacing the loop computations with pre-computed values, leading to significant micro-optimization wins.
**Action:** Mark `faculty`, `facultyRatio`, and `binomialCoefficient` in `include/bspline/internal/misc.h` as `constexpr` to allow the compiler to aggressively optimize compile-time known constants in operations heavily dependent on these utilities.
