## 2024-10-18 - C++ vector of arrays initialization
**Learning:** In C++, constructing a `std::vector` of `std::array` with a default array argument like `std::vector<std::array<T, N>>(size, make_array<T, N>(0))` is significantly slower than using the default value-initialization `std::vector<std::array<T, N>>(size)`. Value-initialization natively zeroes out memory, while explicit construction creates a prototype and invokes the copy constructor for every element in the vector.
**Action:** When initializing a vector of arrays to zero, always use `std::vector<std::array<T, N>>(size)` without an explicit prototype argument. In cases where the array must be initialized but is immediately populated explicitly (as in `SplineOperator.h:transform`), value-initialization (`{}`) is preferred.
