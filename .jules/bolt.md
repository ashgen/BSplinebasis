## 2024-08-14 - Optimize array initialization in BSpline interpolation and generation
**Learning:** In C++, using explicitly filled array copies (`make_array<T>(0)`) with vector initialization incurs a significant overhead (copying instead of default initialization). However, when array elements are completely overwritten, allocating an uninitialized array and writing values iteratively with `push_back()` is generally safe but slower. Wait, as tested, `std::vector<std::array<T, N>>(size)` initializes elements to zero (value-initialization) much faster than copying.
**Action:** Replace `internal::make_array` with simple value initialization in cases where arrays are initialized to zero, or reserve space and push uninitialized elements in cases where elements will be entirely overwritten, avoiding unnecessary zeroing overhead.
