## 2024-08-24 - [Value Initialization vs Explicit Filling in Arrays]
**Learning:** Explicitly constructing a zero-filled `std::array` (e.g., using a custom `make_array` with `.fill()`) and passing it to initialize a `std::vector` (or local arrays) prevents the compiler from optimizing it into a single fast continuous memory clearing operation (like `memset`). By relying on C++ native value-initialization (`std::array<T, N>{}` or `std::vector<std::array<T, N>>(size)`), zero initialization of arrays inside vectors becomes almost instant, whereas explicit copies trigger iteration and assignment overhead which makes initialization >10x slower on large data sizes.
**Action:** Always prefer native value-initialization over explicitly instantiating prototype zero-filled arrays to initialize C++ structures.
