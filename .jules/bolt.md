## 2024-05-20 - Constexpr math & Array Initialization
**Learning:** In this C++17 codebase, `std::array::fill` is not `constexpr`. Additionally, explicit loop zeroing of arrays (e.g. `changearraysize`) is less optimal than utilizing aggregate value initialization (`std::array<T, N> ret{};`) which securely zeros the entire array faster using highly optimized underlying instructions. Pure mathematical functions like `faculty` and `binomialCoefficient` can easily be marked `constexpr` if `std::min/max` usage inside them is replaced by ternary operators (since C++14 constexpr support for std::min/max might be inconsistent or it restricts pure logic), enabling massive compile-time evaluation.
**Action:** Always prefer aggregate value initialization (`std::array<T, N> arr{};`) over manual zero loops for arrays and use `constexpr` for static combinatorial math functions.
