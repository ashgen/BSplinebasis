## 2024-07-31 - [Array zero initialization bottleneck]
**Learning:** Initializing `std::vector<std::array<T, N>>` triggers `T()` element zero-initialization by default for `std::array`. This is extremely slow compared to uninitialized stack arrays because of redundant writes when the elements will immediately be overwritten anyway. Using `std::vector::reserve()` and `std::vector::push_back(temp)` where `temp` is an uninitialized stack `std::array` skips the redundant write. Even `std::vector(N, make_array(0))` is slightly faster than default construction `std::vector(N)`, but `reserve` + `push_back` is fastest.
**Action:** When a vector of `std::array` is immediately overwritten, avoid default constructor `std::vector(N)`. Prefer `reserve` followed by `push_back` of a stack array to prevent default zero-filling.
