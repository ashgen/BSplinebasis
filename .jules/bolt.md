## 2024-05-19 - Compile-Time Precomputation of Binomial Coefficients and Fast Initialization
**Learning:** In heavily utilized utility functions, marking purely mathematical functions like `binomialCoefficient` and `faculty` as `constexpr` allows constant folding and compile-time precomputation using `std::index_sequence`. Additionally, for local arrays `std::array<T, N> arr{}`, aggregate initialization is significantly faster than declaring an array and explicitely zero-filling it (`arr.fill(0)`), as the compiler can optimize the aggregate initialization to a `memset`. In scenarios where all elements are overridden in a loop, default initialization (`std::array<T, N> arr;`) avoids an unnecessary O(N) zero-filling step, further speeding up the execution.
**Action:** Always identify pure mathematical utility methods and add `constexpr` for compile-time processing. Prefer aggregate zero-initialization for `std::array` instead of explicit zero-filling, except when all elements are overwritten immediately, in which case default initialization is optimal.
