## 2024-05-15 - Compile-time math optimization and value-initialization
**Learning:** In C++17, explicitly wrapping `std::array` zero-filling (via `.fill()`) prevents `constexpr` evaluation and adds runtime overhead. Furthermore, constructing a `std::vector` of arrays with explicit default elements (e.g. `std::vector<std::array<T, N>>(size, make_array<T, N>(0))`) is slower than simple value-initialization (`std::vector<std::array<T, N>>(size)`), because the latter directly zeros memory.
**Action:** Mark pure mathematical utilities (like `faculty` and `binomialCoefficient`) as `constexpr` to allow the compiler to perform constant folding. Prefer value-initialization (`std::vector<std::array<T, N>>(size)` or `std::array<T, N>{}`) over explicit wrapper functions that use `.fill()` when initializing zeroed arrays.
